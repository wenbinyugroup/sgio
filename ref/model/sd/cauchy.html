Cauchy Continuum Model#

Note

The legacy dataclass-based CauchyContinuumModel and the transitional CauchyContinuumModelNew alias have both been removed. The Pydantic implementation now carries the canonical name CauchyContinuumModel.

Cauchy continuum model with Pydantic validation.

This implementation follows the beam model pattern and provides built-in validation for all material properties.
