classmethod from_fe(fe_model: FEModel, sgdim: int | None = None, smdim: int | None = None, spdim: int | None = None) → StructureGene#

Wrap an existing FEModel into a StructureGene.

Symmetric to StructuralModel.from_fe(): the fe_model is deep-copied to back the SG’s FE core, SG-specific dimensions come from the arguments, and analysis_config keeps its constructor defaults (to be set by the caller or adapter afterwards).

Parameters:

  • fe_model (FEModel) – Source finite element model.

  • sgdim (int, optional) – Dimension of the SG.

  • smdim (int, optional) – Dimension of the material/structural model.

  • spdim (int, optional) – Dimension of the space containing the SG. Defaults to sgdim.

Returns:

New structure gene with a deep-copied backing FEModel.

Return type:

StructureGene
